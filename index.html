Módulo 2

Caso financiero y modelado

Aplicación ilustrativa para cuatro unidades organizacionales.

Contexto

Una organización desea planificar recursos para cuatro unidades: infraestructura tecnológica, ciberseguridad, capacitación e innovación. El modelo permite estudiar una asignación compatible con necesidades y relaciones internas.

x₁ — Infraestructura tecnológica

Equipamiento, redes, servidores y mantenimiento.

x₂ — Ciberseguridad

Protección de información y continuidad.

x₃ — Capacitación

Formación y actualización del personal.

x₄ — Innovación

Mejora de procesos y desarrollo de proyectos.

Unidad de análisis

x₁, x₂, x₃, x₄ se expresan en unidades presupuestarias normalizadas (UPN). Una UPN es una unidad didáctica de capacidad de recursos y no equivale automáticamente a bolivianos.

b representa necesidades netas priorizadas en UPN. A es una matriz adimensional de ponderaciones y acoplamientos.

Interpretación de los coeficientes

La diagonal aᵢᵢ representa la intensidad de requerimiento propio de la unidad i. Los elementos fuera de la diagonal representan acoplamientos entre unidades. La simetría aᵢⱼ=aⱼᵢ representa una relación mutua en este modelo didáctico.

Importante: los datos son sintéticos e ilustrativos. No son presupuestos reales de la UMSA ni de una empresa. Para una aplicación financiera real se deben recopilar datos institucionales autorizados, definir unidades monetarias y calibrar cada coeficiente.

Aplicación a Ingeniería de Sistemas

El flujo del sistema es: captura → validación → modelado → solución directa → GC/GCP → errores y condicionamiento → reporte. La interfaz gestiona datos, el motor numérico ejecuta algoritmos y QA verifica reglas funcionales.

Módulo 3

Modelo matemático Ax=b

Formulación, simetría y definición positiva.

Ax = b

A: matriz de coeficientes y acoplamientos.
x: vector de cuatro asignaciones desconocidas.
b: vector de necesidades del escenario.

Los métodos GC y GCP requieren una matriz simétrica definida positiva. La aplicación comprueba simetría, realiza Cholesky y calcula los menores principales líderes mediante el criterio de Sylvester.

Carga y ejecuta un escenario para visualizar la verificación.
Para el escenario mal condicionado se utiliza A = DTD, con D no singular y T simétrica definida positiva. Por tanto, para cualquier y≠0: yᵀAy=(Dy)ᵀT(Dy)>0.
